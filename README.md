# Ambient Occlusion for EEVEE Next
Small vibe-coded addon

## Requirements

- Blender 5.2+. The code (how Claude says) contains fallback branches for 4.2-4.5, but they have not been tested.
- Only for EEVEE render engine.

## Known issues

- Unstable behavior with Depth of Field on the camera. Defocus is configured approximately, so check the result manually.
- Works with the active View Layer only.
